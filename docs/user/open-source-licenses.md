# Open source licenses

Ronin includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → General**, find **Open source licenses** under **About**,
  and select **View licenses**.

The page lists the version when available, license identifier, and the parts of Ronin that include
or use the item. This also covers optional device tools that Ronin installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.

The manifest downloads once per app session. Returning to the page reuses the loaded notices.
If downloading fails, choose **Try again** to make another request.
